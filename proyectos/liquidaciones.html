Automatización de generación y distribución de liquidaciones

Automatización del proceso completo de generación y distribución de liquidaciones por cliente, utilizando información estructurada para generar documentos y preparar automáticamente los correos correspondientes.

Antes Varias horas
Después 5–10 min
Resultado Automatizado

Contexto

El proceso requería generar documentos de liquidación asociados a diferentes clientes y operaciones.

La liquidación contiene la información correspondiente al importe que debe ser pagado al cliente o canal por concepto de una comisión o servicio.

Para iniciar el proceso se utilizaba una tabla con la información necesaria de cada operación, incluyendo datos del cliente, RUC, canal, importe y otros campos requeridos para generar la liquidación.

El problema

El proceso manual requería generar las liquidaciones individualmente y posteriormente preparar los correos correspondientes para cada cliente.

Debido a la naturaleza repetitiva del proceso, la ejecución podía consumir varias horas y existía riesgo de cometer errores u omisiones.

El reto Reducir el trabajo manual y disminuir el riesgo de omisiones durante la generación y distribución de las liquidaciones.

Omisiones

Posibilidad de olvidar el envío de alguna liquidación.

Adjuntos

Riesgo de olvidar incorporar algún documento al correo.

Digitación

Posibilidad de introducir incorrectamente información durante el proceso.

Tiempo

Varias horas dedicadas a tareas repetitivas de generación y distribución.

La solución

Se desarrolló una automatización en Excel/VBA capaz de procesar la información de entrada, identificar los datos correspondientes a cada cliente y generar las liquidaciones necesarias.

Una vez generados los documentos, la solución prepara la distribución mediante Outlook, asociando a cada cliente su destinatario, asunto, cuerpo del mensaje y documento correspondiente.

Información de entrada

La automatización utiliza una tabla estructurada como fuente de información para procesar las liquidaciones.

Cliente

Identificación del cliente asociado a la liquidación.

RUC

Identificador necesario para la documentación.

Canal

Información correspondiente al canal asociado a la operación.

Importe

Información económica utilizada para generar la liquidación.

Generación de liquidaciones

A partir de la información procesada, la automatización genera el documento de liquidación correspondiente a cada cliente, considerando las reglas definidas para el proceso.

Esto elimina la necesidad de preparar manualmente cada documento y permite generar las liquidaciones a partir de una única fuente estructurada de información.

Distribución automática

Una vez generadas las liquidaciones, la solución utiliza Outlook para preparar el correo correspondiente a cada cliente.

Destinatario

Asociado automáticamente al cliente correspondiente.

Asunto

Generado según las reglas definidas para el proceso.

Cuerpo

Preparado automáticamente con la estructura correspondiente.

Adjuntos

Se incorpora la liquidación correspondiente al cliente.

Cuando un cliente requiere un tratamiento particular, la estructura permite realizar ajustes específicos antes de completar el proceso.

Impacto

La automatización transformó un proceso que requería varias horas de trabajo en una ejecución de aproximadamente 5–10 minutos.
