Automatización de generación y distribución de liquidaciones

Diseño y desarrollo de una solución para automatizar el proceso de generación y distribución de liquidaciones, utilizando información estructurada para generar los documentos correspondientes y preparar automáticamente los correos asociados a cada cliente.

Antes Varias horas
Después 5–10 min
Resultado Automatizado

Contexto

El proceso requería generar documentos de liquidación asociados a diferentes clientes, operaciones y conceptos de pago.

La liquidación contiene la información correspondiente al importe que debe ser pagado al cliente o canal por concepto de una comisión o servicio.

Para iniciar el proceso se utilizaba una tabla estructurada con la información necesaria de cada operación, incluyendo datos del cliente, RUC, canal, importe y otros campos requeridos para generar la documentación.

El problema

El proceso manual requería generar las liquidaciones individualmente y posteriormente preparar los correos correspondientes para cada cliente.

Debido a la cantidad de operaciones y al carácter repetitivo de las tareas, la ejecución podía consumir varias horas y existía riesgo de cometer errores u omisiones durante la preparación y distribución.

Omisiones

Posibilidad de olvidar el envío de alguna liquidación o dejar una operación sin procesar.

Adjuntos

Riesgo de olvidar incorporar el documento correspondiente al correo.

Digitación

Posibilidad de introducir incorrectamente información durante la preparación manual.

Tiempo

Varias horas dedicadas a tareas repetitivas de generación y distribución.

El reto Reducir el trabajo manual y disminuir el riesgo de errores y omisiones durante la generación y distribución de las liquidaciones.

La solución

Diseñé y desarrollé una automatización en Excel/VBA capaz de procesar la información de entrada, identificar los datos correspondientes a cada cliente y generar las liquidaciones necesarias.

Una vez generados los documentos, la solución prepara la distribución mediante Outlook, asociando a cada cliente su destinatario, asunto, cuerpo del mensaje y documento correspondiente.

Información de entrada

La automatización utiliza una tabla estructurada como fuente de información para procesar las liquidaciones y determinar los datos necesarios para cada documento.

Cliente

Identificación del cliente asociado a la liquidación.

RUC

Identificador utilizado dentro de la documentación correspondiente.

Canal

Información correspondiente al canal asociado a la operación.

Importe

Información económica utilizada para generar la liquidación.

Generación de liquidaciones

A partir de la información procesada, la automatización genera el documento de liquidación correspondiente a cada cliente, aplicando las reglas definidas para el proceso.

Esto elimina la necesidad de preparar manualmente cada documento y permite generar las liquidaciones utilizando una única fuente estructurada de información.

Una fuente → múltiples documentos La información estructurada permite procesar las operaciones y generar las liquidaciones correspondientes de forma automatizada.

Distribución mediante Outlook

Una vez generadas las liquidaciones, la solución utiliza Outlook para preparar el correo correspondiente a cada cliente.

Destinatario

Asociado automáticamente al cliente correspondiente.

Asunto

Generado según las reglas definidas para el proceso.

Cuerpo

Preparado automáticamente utilizando la estructura correspondiente.

Adjuntos

Se incorpora la liquidación correspondiente al cliente.

Cuando un cliente requiere un tratamiento particular, la estructura permite realizar ajustes específicos antes de completar el proceso.

Impacto

La automatización transformó un proceso que requería varias horas de trabajo en una ejecución de aproximadamente 5–10 minutos.

Varias horas → 5–10 minutos Reducción significativa del tiempo dedicado a la generación y distribución de liquidaciones.
